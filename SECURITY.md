# Security Policy

## Supported Versions

Security fixes are applied to the latest published version of `@devxbhuvn/array-fns`.

| Version              | Supported |
| -------------------- | --------- |
| Latest `1.x` release | Yes       |
| Older releases       | No        |

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public issue.

Report a suspected vulnerability privately to the project maintainer using the contact information in the repository or npm package metadata. Include:

- The affected package version.
- The affected function or file, if known.
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- A minimal proof of concept, when safe to provide.
- Any suggested mitigation.

You will receive an acknowledgement as soon as practical. The maintainer will investigate the report, work on a fix, and coordinate disclosure when appropriate.

## Scope

This policy covers the published package and its source code. Reports about third-party dependencies should also be reported to their maintainers, although relevant findings may be shared with this project when they affect package users.
